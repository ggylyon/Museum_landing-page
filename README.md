## 🖼 About the Project

The **Museum Landing Page** is a responsive website inspired by the National Art Museum of Ukraine.

The main goal of the project is to create an elegant and user-friendly online experience that introduces visitors to the museum, its exhibitions, cultural events, and Ukrainian art.

The design focuses on visual presentation, clear navigation, and accessibility across different devices.

## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### 1. Clone the repository

```bash
git clone https://github.com/ggylyon/Museum_landing-page.git
```

### 2. Navigate to the project directory

```bash
cd Museum_landing-page
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

Open the local URL displayed in your terminal to view the website.
